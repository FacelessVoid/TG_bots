# Telegram Bot для обработки заявок

Telegram-бот для приёма и обработки заявок от клиентов.

## Возможности

### Для клиента

- 📝 Создание заявки
- 👤 Профиль пользователя
- 📊 Статистика заявок
- 📨 Просмотр своих заявок
- 🟡 Отслеживание статуса заявки
- ❌ Отмена заявки с подтверждением
- 🔔 Получение уведомлений об изменении статуса

### Для администратора

- ⚙️ Административная панель
- 📨 Просмотр всех заявок
- 🔎 Просмотр подробной информации о заявке
- 💬 Переход к Telegram-профилю клиента
- ✅ Отметка заявки как выполненной
- ↩️ Возврат заявки в работу
- 🗑 Удаление заявки с подтверждением
- 🔔 Уведомления об отмене заявок
- 🔗 Быстрый переход к заявке из уведомления

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/FacelessVoid/TG_bots.git
cd TG_bots
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его:

### Windows

```bash
.venv\Scripts\activate
```

Установите зависимости:

```bash
pip install aiogram python-dotenv
```

## Настройка

В папке `Example_bot` создайте файл `.env`:

```env
BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id
```

`BOT_TOKEN` — токен Telegram-бота, полученный через BotFather.

`ADMIN_ID` — Telegram ID администратора.

## Запуск

Перейдите в папку проекта:

```bash
cd Example_bot
```

Запустите бота:

```bash
python main.py
```

## Безопасность

Файл `.env` не должен публиковаться в GitHub.

Токены и другие секретные данные хранятся в переменных окружения.

Локальная база данных SQLite также не загружается в репозиторий.

## Статусы заявок

```text
🟡 В работе
      ↓
🟢 Выполнена
```

Пользователь также может отменить активную заявку:

```text
🟡 В работе
      ↓
🔴 Отменена
```

Администратор может вернуть отменённую или выполненную заявку обратно в работу:

```text
🟢 Выполнена / 🔴 Отменена
              ↓
        🟡 В работе
```
